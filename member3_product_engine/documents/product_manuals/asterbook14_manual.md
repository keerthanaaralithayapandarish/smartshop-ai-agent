# AsterBook 14 – Sample product manual

## Display and external monitor connection
The AsterBook 14 includes one HDMI port and one USB-C port. Check the exact display output capability of the USB-C port in the manufacturer's current technical documentation before relying on USB-C video output. An HDMI display can be connected using a suitable HDMI cable.
